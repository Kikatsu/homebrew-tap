# Kikatsu's Homebrew tap

```sh
brew install --cask kikatsu/tap/pip-notch
```

| Cask | App |
| --- | --- |
| `pip-notch` | [Pip](https://github.com/Kikatsu/pip-notch), a notch companion that shows what your AI coding agents are doing |

Update with `brew upgrade --cask pip-notch`. Casks here are updated automatically when a new release is published.
